DESCRIPTION:  he Inverted Search project is a C-based application that creates an index 
of words from multiple text files using hash tables and linked lists. It stores each 
unique word along with the file names in which it appears and the number of occurrences.
The project supports creating, displaying, searching, saving, and updating the database, 
enabling fast and efficient word searches across multiple files. It demonstrates concepts 
such as data structures, file handling, dynamic memory allocation, and hashing.

Features
* Validates input text files.
* Rejects invalid, empty, or duplicate files.
* Creates an inverted index using a hash table with 27 indices.
* Stores:
    * Word
    * Number of files containing the word
    * File names
    * Word occurrence count in each file
* Supports efficient word searching.
* Displays complete database contents.
* Saves the database into a backup file.
* Restores the database from a backup file.
* Handles multiple files dynamically using linked lists.
