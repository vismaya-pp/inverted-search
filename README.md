# Inverted Search in C

## Overview
Inverted Search is a file indexing and searching application implemented in C. It uses a hash table and linked lists to index words from text files and efficiently retrieve the files in which a particular word appears.

## Features
- Create an inverted index from text files
- Search for a word and identify the files containing it
- Store word frequencies and file associations
- Display indexed data
- Save and update the database
- Efficient searching using a hash table

## Technologies Used
- **Programming Language:** C
- **Data Structures:** Hash Tables and Linked Lists
- **Concepts:** File Handling, Pointers, Dynamic Memory Allocation, String Processing

## Project Structure
The project is organized into C source files and header files for indexing, searching, database management, and related operations.

## How to Compile and Run

1. Clone the repository:
   ```bash
   git clone https://github.com/vismaya-pp/inverted-search.git
   ```

2. Navigate to the project folder:
   ```bash
   cd inverted-search
   ```

3. Compile the source files using your project's Makefile, if available. Otherwise, use the appropriate GCC command for your source files.

4. Run the generated executable and follow the program's menu or input instructions.
